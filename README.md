Правила игры в «Морской бой», в которой участвуют два игрока.
Игроки выполняют вход: каждый в свой отдельный аккаунт.
Прежде чем выполняется вход необходимо пройти регистрацию.
Один из игроков начинает игру и копирует её уникальный номер, непосредственно передавая этот номер второму игроку.
Второй игрок присоединяется к игре, после того как вводит этот номер  в поле и нажимает кнопку "присоединиться".
Игроки выполняют размещение кораблей по правилам игры "морской бой" ( а именно: корбали не размещаются по диагонали, только напрямую, между кораблями есть расстояние в одну клетку).
Флот каждого игрока состоит из 10 кораблей (20 белых кнопок-клеток)
1 линкор — четырёхпалубный корабль, который занимает 4 клетки поля;
2 крейсера — трёхпалубники, занимающие по 3 клетки;
3 эсминца — двухпалубные корабли, занимающие по 2 клетки;
4 катера — однопалубные судна, обозначающиеся 1 клеткой.
Очередность ходов определяется самостоятельно.
При попадении - клетка-корабль/клетка-палуба обозначается крестиком.
При промахе - обозначается точкой.
 Игра продолжается до тех пор, пока один из участников не потопит весь флот соперника.
